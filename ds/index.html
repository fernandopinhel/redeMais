Orla DS

Um design system para três produtos diferentes.

O Orla DS dá a base comum: tokens, componentes, ícones e comportamentos acessíveis. Cada produto troca só a escala de cor e monta o seu próprio layout. Tudo em CSS e JavaScript puros, sem framework.

Cores de base

Neutros e estados são iguais em toda a suíte. Texto tem contraste de pelo menos 4,5:1, e bordas de campo, de 3:1.

    Temas dos produtos

    Cada produto define a escala --accent-50 a --accent-900, uma cor de apoio (--signal) e os tons da noite do login. Os componentes leem só esses tokens.

    Tipografia

    Manrope nos títulos e Inter no texto, só com os pesos 400, 500 e 600, para a interface ficar leve. Números em tabelas usam algarismos de largura fixa.
