Observações


1 - Regime de Atendimento
No caso de negociação hospitalar deverá ser informado se a negociação é exclusiva para um determinado Regime de Atendimento. Como por exemplo negociação de agravo no SADT: informar se a negociação é válida somente para paciente internado ou valerá também para o Pronto Socorro;

2 - Procedimento Padronizado (Exceto REDE+)
Em negociação de Procedimento Padronizado informar o código TUSS e a composição do PP;

3 - Diárias e Taxas
A tabela de D&T deverá ser enviada com a codificação e nomenclatura TUSS;

4 - Rol Não
Não pode ser emitido acordo com procedimentos Rol Não para Mediservice. Para a Bradesco os procedimentos Rol não terão cobertura somente para os procedimentos divulgados no site;

5 - Percentual de Reajuste
O percentual negociado deve ser informado para cada acordo negociado. Exemplo: D&T: 4% | Procedimentos Padronizados: 5% etc.
